How is each club break specified?

What does the user enter to define one break for a club?

A

Start time + End time

e.g. 12:00 → 13:00. Explicit and clear. User picks exactly when the break starts and ends.

B

Start time + Duration

e.g. 12:00 for 60 min. Consistent with how matchLength works today.

C

Duration only — scheduler finds the slot

e.g. "60 min". The scheduler gives the club a gap of at least that length somewhere in the day. No fixed time — maximises flexibility for the scheduler to find the best fit.
