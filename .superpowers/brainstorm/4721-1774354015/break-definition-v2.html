How should each break be defined?

What information does the user provide for a single break?

A

Start time + End time

e.g. 12:00 → 13:00. Explicit, no ambiguity.

B

Start time + Duration

e.g. 12:00 for 60 min. Consistent with how match/break lengths work today.

C

Duration only — app picks the slot

e.g. "60 min break". The app finds a natural slot boundary and inserts the break. Simple to configure — but needs a rule for where to place it.

Placement rule options: after slot N, at the midpoint of the day, or nearest slot to a target time (e.g. "around 12:00")
